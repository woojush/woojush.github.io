# 07. Design Direction (v2)

2026-10-10. 원래 브리프(차분·미니멀·에디토리얼)를 대체하는 새 방향이다.
`docs/04`와 충돌하는 부분은 이 문서가 우선하며, 04의 해당 항목에 같은 내용을 반영했다.

## 1. 왜 바꿨나

Phase 1의 결과가 "정적이고 AI 느낌"이라는 피드백. 원인은 (1) 안전한 회색+청록 팔레트, (2) 비어 있는 메인,
(3) 움직임을 거의 금지한 규칙이다. 목표는 "적당히 동적이고 감각적이며, 메인은 창의적·신박한 첫인상".
이 사이트는 취업용이 아니라 느낀 것을 쌓다 보면 포트폴리오가 되는 아카이브다.

## 2. 레퍼런스에서 가져오는 것

| 레퍼런스 | 가져오는 것 | 가져오지 않는 것 |
|----------|-------------|------------------|
| lifestories.org (`/discover`) | 어두운 바탕, 별가루가 떠 있는 공간, 로딩 뒤 큰 문구가 나타나는 첫 화면 | 장편 섹션 나열, 카드 그리드, 오디오 |
| deck.co | 움직임이 있는 인상 | SaaS 랜딩 구조 |
| doce.sh | 사람 냄새: 프로젝트, now, uses, skills 중심의 구성 | 일상 사진 위주 구성 |

## 3. 움직임 규칙 (허용 범위)

- **a. 마이크로 인터랙션:** 링크·탭·토글의 색/밑줄 전환 140ms.
- **b. 페이지 전환:** 사이트 안 이동 시 CSS View Transitions. 헤더는 고정, 탭 표시가 이전 탭에서 새 탭으로 미끄러지고(600ms), 본문은 크로스페이드. 미지원 브라우저는 평소대로 이동.
- **메인 한정:** 배경 별가루(canvas, 포인터 시차)와 첫 문구의 단어별 등장. 로드당 한 번.
- **c. 탭 바 (2026-10-10 사용자 지시·승인, 위 a·b의 범위를 넘는 예외):** lifestories.org의 상단 알약을 따른다. 데스크톱(마우스)에서는 화면 위 가운데에 떠 있는(fixed) 작은 알약(260px)이고 가운데에 점 4개 허브가 있다. 마우스가 올라가면 스프링(cubic-bezier .44,1.85,.6,1, 600ms, 오버슈트 1회)으로 늘어나고(416px) 벗어나면 같은 스프링으로 줄어들며 글자가 바깥에서 안쪽으로 모이며 나타난다. 알약 배경은 글자색 7%의 옅은 막에 뒤 화면 블러(15px)를 더한 원래 배경이고, 테두리를 8초에 한 바퀴 도는 빛줄기만 있다. 글자에 마우스를 올리면 알약 안쪽 아래 가장자리에서 하얀 빛(opacity .5)의 윗부분 1/5만 보이며 그 글자 밑을 따라 움직인다. 빛은 알약 밖으로 나가지 않는다. 허브는 올라갈 때 90° 돈다. 모바일·터치는 이름 아래 한 줄에 글자가 처음부터 보이는 알약이고 호버 효과가 없다. 이 글로우·빛은 탭 바에만 쓰며 다른 곳으로 넓히지 않는다.
- **금지 유지:** 스크롤할 때마다 요소가 올라오는 효과, 장식 그림자·그라디언트, 자동 슬라이드.
- `prefers-reduced-motion: reduce`이면 위 움직임을 전부 끈다 (문구는 처음부터 보이고, 별가루는 정지 화면, 페이지 전환 없음).

## 4. 색·서체

- **어두운 테마가 기본**, 밝은 테마는 선택. 시스템 설정 추종(system)은 없앴다 (dark ↔ light 두 상태).
- 어두운 바탕은 약간 따뜻한 먹색(#121211), 글자는 따뜻한 흰색(#ebe7df), 포인트는 앰버(#e0a96d). 원래 브리프의 "목재·자연" 쪽으로 맞춘 것이다.
- 포인트 색은 링크·포커스·선택에만 쓴다. 탭의 현재 위치는 색이 아니라 표시 면(`--surface`)과 굵기로.
- 서체는 Pretendard 한 가족을 유지한다. 메인 큰 문구는 `--fs-display`(32~64px).

## 5. 구성

- **상단 탭 바:** 메뉴 4개(projects/about/knowledge/writing, 2026-10-10, home은 메뉴에서 제외)를 §3 c의 알약으로 표시. 각각 별도 URL의 일반 링크(ARIA tabs 아님). 홈은 이름(헤더 왼쪽)과 알약 가운데 허브가 링크한다. 사용자가 향후 직접 수정할 수 있으며 순서와 이름은 유지한다.
- **메인(`/`):** 배경 별가루 + 큰 문구 + 한 줄 설명. NOW·최근 활동은 Phase 4에서 아래에 추가.
- **읽는 페이지(knowledge, writing, about):** 조용하게 유지. 별가루 등 메인 전용 효과 없음.
